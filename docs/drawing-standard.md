## ROLE AND GOAL

You are producing an ASME-style drawing (one sheet for a part; as many sheets as needed for an assembly) for EG1004 team **SLDP 45** (TVC rocket project). It must match our existing drawing SLDP-AV-001 (avionic sled, generated by the attached reference script) **exactly** in sheet format, line weights, fonts, title block, revision block, symbols and layout conventions. Only the part geometry, views, dimensions, notes and title-block values change. When anything below is ambiguous, copy what the reference script does.

- Area code: `{{AREA}}`, one of:

## FILE NAMING (mandatory)

- Format: `SLDP-{{AREA}}-{{VER}}_{{details}}.ext`
  - `details` = short lowercase description, words joined with hyphens, no spaces, no dates, no "final". Part letters and version tags keep their case (`SLDP-ST-005_C1-coupler`, `SLDP-TVC-001_motor-tube-v8`).
  - Suffixes after a second underscore only: `_drawing.py` (generator), `_sheet1.png`… (one PNG per sheet).
  - Example: `SLDP-AV-001_avionic-sled.pdf`, `.png`, the model `SLDP-AV-001_avionic-sled.py` and the generator `SLDP-AV-001_avionic-sled_drawing.py`.
  - CAD files for the same part share the base name: `SLDP-AV-001_avionic-sled.step` / `.stl`.
- The DWG NO. cell on the sheet reads `SLDP-{{AREA}}-{{VER}}` (no description, no revision).
- The revision lives only in the REV cell and the REVISIONS block, not in the file name. A new revision overwrites the same file name inside a new release folder (`releases/batch-NNN_YYYY-MM-DD/`); earlier batches stay in `releases/` unchanged.

## TOOLING

- Python 3, matplotlib (Agg backend), numpy, CadQuery 2.x (`pip install cadquery`).
- Import the part's CadQuery module and read every dimension from its parameters. **Never hard-code a dimension that exists as a model parameter** (so the drawing updates when the model changes).
- Output both: vector PDF (`fig.savefig(pdf)`, default dpi) and PNG at `dpi=170`.

## SHEET AND COORDINATE SYSTEM

- Size: ANSI B landscape, 17 × 11 in = **431.8 × 279.4 mm**.
- `fig = plt.figure(figsize=(17, 11), dpi=150, facecolor='white')`
- One full-figure axes: `ax = fig.add_axes([0, 0, 1, 1])`, `ax.set_xlim(0, 431.8)`, `ax.set_ylim(0, 279.4)`, `ax.axis('off')`, `ax.set_aspect('equal')`.
- **All geometry is drawn in millimetres in sheet coordinates.** One model mm = one sheet mm, so the drawing is true 1:1 when the PDF is printed at 100 % on 11×17. Choose a different scale only if the part does not fit (then use 1:2 or 2:1 and multiply every model coordinate by the scale factor, and state it in the SCALE cell). Never scale a view with an image or transform.
- Origin bottom-left; x right, y up.

## LINE CONVENTIONS (ASME Y14.2)

- `MM2PT = 72/25.4`
- Thick = `0.6*MM2PT` pt — visible outlines and the title-block outer frame. Sheet border = thick × 1.3.
- Thin = `0.3*MM2PT` pt — hidden, center, phantom, dimension, extension and leader lines, frames, title-block inner cells.
- Dash patterns (matplotlib `ls` tuples, exactly):
  - Hidden: `(0, (3/0.85, 1/0.85))`
  - Center: `(0, (12/0.85, 2/0.85, 2/0.85, 2/0.85))`
  - Phantom: `(0, (10/0.85, 2/0.85, 2/0.85, 2/0.85, 2/0.85, 2/0.85))`
- Colour: black only (`'black'`). White background. No fills except datum triangles and arrowheads.
- `solid_capstyle='butt'` on all lines.
- Arrowheads: `arrowstyle='-|>'`, thin line width, `mutation_scale=9`, `shrinkA=shrinkB=0`.

## LETTERING

- Font: **DejaVu Sans** everywhere: `plt.rcParams.update({'font.family': 'DejaVu Sans', 'font.size': 11})`.
- All text **UPPERCASE**.
- Base size `FS = 11` pt (≈3 mm cap height) for dimension values and leader notes.
- Sizes (pt):
  - Dimensions, leaders: 11
  - Feature control frame text, basic dims, notes: 9.5–10 (notes `FS-1.5`, FCF `FS-1`)
  - Phantom-part labels (italic): 8–9
  - Zone labels: 9
  - REVISIONS header: 9 bold; its cells: 8
  - Title-block field labels (top-left of each cell): 6
  - Title-block values: 10 (TEAM, TITLE, MATERIAL, SCALE, MASS, SHEET); 11 (SIZE, DWG NO., REV); 7.5 (DATE)
  - Tolerance block text: 6.5; "THIRD ANGLE PROJECTION": 4.8
- **Bold only** for: "NOTES:" heading, view captions (e.g. "ISOMETRIC VIEW (REF)"), "REVISIONS" header, datum letters. **Nothing in the title block is bold.**
- Text horizontal (unidirectional) — never rotated with the dimension line.

## BORDER, ZONES

- Border rectangle inset 10 mm on all sides (`box(10, 10, SW-10, SH-10)`), thick × 1.3.
- 8 columns numbered 8→1 left to right, top and bottom margins, centred at y = 5 and SH-5.
- 4 rows lettered A→D bottom to top, left and right margins, centred at x = 5 and SW-5.
- Zone division ticks: thin, 3 mm long, pointing **outward** from the border into the margin (never into the drawing area or title block).

## REVISIONS BLOCK (top-right, inside border)

- Box 120 × 19 mm, top-right corner at (SW-10, SH-10), thin lines.
- Rows: header strip "REVISIONS" (top 6 mm), column labels row, one data row per revision.
- Column dividers at +14 mm and +92 mm from the left edge: REV | DESCRIPTION | DATE.
- Text centred in each column. Add a row (grow the box downward) for each new revision; keep all previous rows.

## TITLE BLOCK (bottom-right, inside border) — exact geometry

Origin `tbx = SW-10-150`, `tby = 10`; overall 150 × 52 mm, outer frame thick, cells thin. Each cell: field label at top-left (+1.2, -1.2 mm, 6 pt, not bold); value centred horizontally at 42 % of the cell height.

| Row (y from tby) | Cells left → right (width mm): LABEL = value |
|---|---|
| Top, y 36–52 (h 16) | 52: TEAM = `SLDP 45` · 98: TITLE = `{{PART NAME}}\n{{ASSEMBLY}}` (two lines) |
| Middle, y 18–36 (h 18) | 52: UNLESS OTHERWISE SPECIFIED = tolerance block · 18: SIZE = `B` · 62: DWG NO. = `SLDP-{{AREA}}-{{VER}}` · 18: REV = `{{REV}}` |
| Bottom, y 0–18 (h 18) | 30: third-angle symbol cell (no field label) · 22: DATE · 24: MATERIAL · 20: SCALE = `1:1` · 26: MASS · 28: SHEET = `n OF N` |

- Tolerance block text (left-aligned at tbx+1.5, top at tby+31, 6.5 pt), exactly:
  ```
  DIMENSIONS ARE IN MM
  TOL: X ±0.5  X.X ±0.2
         X.XX ±0.1  ANGLES ±1°
  DO NOT SCALE DRAWING
  ```
- **No DRAWN / CHECKED / APPROVED fields.** No personal names anywhere on the sheet.

## THIRD-ANGLE PROJECTION SYMBOL (in the 30 × 18 cell)

- Caption "THIRD ANGLE PROJECTION", 4.8 pt, centred at (tbx+15, tby+15.5).
- **Circles on the LEFT**, frustum on the RIGHT, with the frustum's **small end facing the circles**.
  - Circles centred at (tbx+8, tby+7), radii 4.2 and 2.1.
  - Frustum polygon: (tbx+15.5, cy∓2.1) small end, (tbx+27, cy±4.2) large end.
  - Line width thin × 1.4.
  - Centre lines (thin × 0.8, center pattern): horizontal through both from cx-5.5 to tbx+28.5; vertical through the circles ±5.5.

## VIEWS (ASME Y14.3, third-angle)

- Choose the **front view** as the most descriptive view, with the part in its functional orientation (rocket axis vertical, tail down).
- Placement:
  - Top view directly **above** the front view, sharing the same x.
  - Right-side view directly **to the right**, sharing the same y.
  - Left/bottom views only if needed (left of front, below front).
- Alignment by construction: define one set of view origins and derive everything from them, e.g.
  - `XF, YF` = front-view origin
  - `YT = YF + H + gap + R` = top-view centre
  - `XR = XF + R + gap + R` = right-view centre
  - Gaps between views 34–50 mm so dimensions fit between them. Reference values from SLDP-AV-001: `XF, YF = 85, 40`.
- Use only as many views as needed to fully define the part (normally front + top + right). Omit a view that adds nothing.
- **No "FRONT VIEW / TOP VIEW / RIGHT SIDE VIEW" captions** on principal aligned views.
- Captions only on non-aligned views: section ("SECTION A-A"), detail ("DETAIL B, SCALE 2:1"), isometric. Bold, `FS-1`, centred below the view.
- Hidden lines: show those needed for understanding (holes, internal features). Don't dimension to hidden lines.
- Center lines on every axis of symmetry and every hole/boss, extending ~3–6 mm past the feature.
- Mating or reference parts (breadboard, PCB, motor, etc.) are drawn as **phantom** lines with an italic label, e.g. "HALF-SIZE BREADBOARD (PHANTOM)".
- Use a section view (with cutting-plane line and hatch at 45°, thin, 3 mm spacing) when internal features are not clear with hidden lines.

## ISOMETRIC VIEW (REF)

- Generated from the CAD model, not hand-drawn:
  ```python
  cq.exporters.export(model, svg_path, opt={'width': 400, 'height': 400, 'showAxes': False,
       'projectionDir': (1, -1, 0.8), 'showHidden': False, 'strokeWidth': 0.3})
  ```
- Parse only the `<!-- solid lines -->` section's path `d` coordinates. Centre on the bounding-box middle; flip y if the part appears upside down.
- Draw as **black line work only** (thin × 1.2, no shading, no hidden lines).
- Place in the upper-right open area, clear of the revisions block and notes. Reference: centre (352, 196) at scale 0.5.
- Caption below: "ISOMETRIC VIEW (REF)\nSCALE 1:2" (or its actual scale), bold, FS-1. Never dimension the isometric.

## DIMENSIONING RULES (ASME Y14.5)

- Units mm; no "mm" after values. Decimal format follows the tolerance block: whole numbers (±0.5) for non-critical sizes, one decimal (±0.2) for moderate, two decimals (±0.1) only when needed. Explicit tolerances (e.g. `Ø75.8 ±0.1`) on critical fit features.
- Each feature dimensioned **once**, in the view where its shape is most visible. **No duplicate dimensions** across views.
- No dimensions on hidden lines, none inside the part outline unless unavoidable.
- Extension lines start 1.5 mm off the part and run 2 mm past the dimension line.
- First dimension line ≥ 8–10 mm from the outline; successive parallel dimensions 10–11 mm apart; shortest dimension closest to the part. Don't cross dimension lines with extension lines.
- Small dimensions (< ~10 mm): arrows outside pointing in, value outside (see `dim_small_v`).
- Symbols: `Ø` diameter, `R` radius, `↧` depth, `nX` for repeated features (e.g. "4X Ø2.5 ↧ 7", "2X LEDGE 56X4X2"), `THRU` for through features.
- Leaders: thin, angled (not horizontal or vertical), with a 5 mm horizontal shelf, arrow at the feature edge, note text in line with the shelf.
- Reference-only dimensions in parentheses, e.g. `(76.2)`.
- Text never overlaps lines, other text, views, or the title block. Everything stays inside the border.

## GD&T (keep it consistent and minimal)

- Datums: A = primary mounting / bearing face (usually the bottom face or the face that sits on the bed); B = main locating diameter or edge; C = secondary face for orientation.
- Datum feature symbol: thin leader, filled equilateral triangle (base 3.6 mm) on the feature or its extension line, 7 × 7 mm square frame with the bold letter.
  - Attach to the dimension line for a size feature (axis datum).
  - Attach to the surface or extension line for a plane.
- Feature control frames: 6.5 mm tall, thin box. First cell 7.5 mm wide holding the drawn symbol; other cells sized to their text.
  - Draw the symbols with lines, not Unicode:
    - Position: circle r 1.6 + cross ±2.6
    - Flatness: parallelogram
    - Perpendicularity: ⊥ built from two lines
- Typical tolerances for FDM PLA parts:
  - Flatness 0.3
  - Perpendicularity 0.3 to A
  - Position Ø0.4 to A B on holes, located by **basic dimensions** (value in a thin rectangular box).
- Don't over-tolerance: only control features that affect fit or alignment.

## NOTES

- Block heading "NOTES:" (bold), left-aligned, placed in open space above the title block (reference: x = 288, starting y = 152, line pitch 6.3 mm, size FS-1.5).
- Numbered 1, 2, 3…; continuation lines indented 3 spaces; wrap at ~45 characters; uppercase.
- Standard order:
  1. Material and print process
  2. Print orientation / supports
  3. Assembly / fastening
  4. Part-specific requirements
- Do **not** include "INTERPRET PER ASME Y14.5" or "SHOWN PHANTOM FOR REFERENCE" notes (team preference).

## CONSISTENCY WITH OUR PROJECT FACTS

- Body tube ID 76.2 mm, OD 78.6 mm (rocket v5, SLDP-ST-005).
- Sliding parts are 0.2 mm radial clearance (sled Ø75.8). Couplers are a deliberate tighter slip fit: 0.15 mm radial.
- Fasteners: M3 self-tapping into Ø2.5 pilot holes; Ø3.2 clearance.
- Print on Bambu (≤ 254 mm in any direction); PLA density 1.24 g/cm³.
- Axes: z = rocket axis (0 at the tail), +X = toward the 2× M3 TVC mount screws (body 0°). Pivot axes are named as on SLDP-TVC-001.

## QUALITY CHECK BEFORE DELIVERING (do all, and say which you checked)

1. Measure: a known model length (e.g. overall height) is the same number of sheet mm in every orthographic view.
2. Views aligned: top-view features line up vertically with the front view, right-view features horizontally.
3. Render the PNG and inspect it. No overlapping text, no lines through text, nothing outside the border, no ticks inside the title block.
4. Every feature needed to make the part is dimensioned exactly once; no dimension to a hidden line.
5. Title block:
   - Values correct; DWG NO. = `SLDP-{{AREA}}-{{VER}}`; REV matches the revisions block.
   - Third-angle symbol has circles on the left.
   - Nothing bold.
6. File names follow `SLDP-{{AREA}}-{{VER}}_{{details}}`.
7. Report the mass and bounding box from the CAD model, and any design issues found while drawing (fit, printability).
